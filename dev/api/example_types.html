6.6. Example Types¶

6.6.1. Position¶

Positioned objects, as a tree of frames rooted in a RootFrame.

Frame conventions:

  • ECEF (the usual root): metres; x through the equator at the prime meridian, y through the equator at 90°E, z through the north pole.

  • Body frames are FRD: x forward, y right, z down – MAVLink’s and aerospace’s convention, so autopilot attitudes go in without conversion. A camera mounted 10 cm ahead of a drone’s centre is Offset(x=0.1).

  • Local level frames are NED (x north, y east, z down); Orientation.ned_to_ecef() places one on the globe.

  • An Orientation rotates vectors from the child’s frame into its parent’s, so child.offset.rotate_by(parent.orientation) is the child’s offset expressed in the parent’s parent.

class SpiriSynq.example_types.position.Accuracy(horizontal=None, vertical=None)[source]¶

Bases: object

Positional accuracy expressed as error bounds at 90% confidence.

There should be a 90% chance the object is inside of this cylinder.

Stored as CEP90/LEP90.

We break from ATAK/CoT here. On CoT ce/le uses 1-sigma (one standard deviation), which corresponds to ~39% confidence for horizontal (2D Rayleigh) and ~68% for vertical (1D Gaussian) — use at_confidence() to convert.

The intent behind this difference is that it’s easy to convert, and provides developers with an easy and intuitive understanding of their confidence bounds. It roughly tracks to an intuitive “The object is here”.

horizontal: radius in metres of the circle within which the true

horizontal position lies with 90% probability (CEP90).

vertical: half-height in metres of the vertical band within which

the true altitude lies with 90% probability (LEP90).

Parameters:

  • vertical (float | None)

compose(child)[source]¶

Place child, given in this pose’s local frame, into the frame this pose is in.

The standard rigid-body chain, T_child = T_parent ∘ T_mount:

offset = parent.offset + child.offset.rotate_by(parent.orientation)
orientation = parent.orientation * child.orientation

Accuracies combine in quadrature; whichever is known propagates.

A point has no axes to measure from: under one, a child at a zero offset is a point at the same place, and any other child can’t be placed, so this returns None. A point child stays a point.

Parameters:

child (Pose)

class SpiriSynq.example_types.position.Position(synq_topic, synq_base_topic=None, synq_session=<factory>, synq_authoritive=False, synq_lazy_publish=False, synq_publish=True, synq_receive=True, synq_auto_start=True, synq_check_receive_types=True, synq_auto_rehydrate_on_missing_parent_timeout=5.0, synq_mtime=-1, synq_is_deleted=False, _synq_callbacks=<factory>, _synq_last_rehydrate_time=0.0, relative_to='unknown', mount=None, pose=None, _parent_subscriber=None, _parent_pose=None, _parent_live=False, _parent_generation=0)[source]¶

Bases: SyncableObject

Something with a place in the world: a node in a tree of frames.

relative_to names the parent: a RootFrame, or the topic of another Position: a Link, or a topic string (absolute, or relative like ./origin). Prefer a Link: a relative topic means something different on every node that receives it. mount is this object’s pose in its parent’s frame – the value you set. pose is the resulting pose in the root frame, which the authoritative node computes and publishes; mirrors just receive it.

pose is None until it can be computed: without a mount, or while the parent’s own pose is unknown. An unknown parent is never treated as the identity, which would put the object near the root frame’s origin.

SpiriSynq.example_types.position.fuse_positions(*positions)[source]¶

Fuse N independent position observations into a single best estimate.

Uses inverse-variance weighting when horizontal/vertical accuracies are known, falling back to a simple mean otherwise. More observations with known accuracy produce a tighter result. Positions whose pose is unknown are skipped.

Returns (offset, accuracy) where either component may have None fields if no accuracy information was available for that axis.

Parameters:

positions (Position)

Return type:

tuple[Offset, Accuracy]
