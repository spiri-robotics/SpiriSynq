# SpiriSynq v1 documentation (reference only)

These are the docs for SpiriSynq v1, the pure-Python implementation, as they stood when work on
v2 (the Rust core, branch `feat/rust-core`) began. They aren't built or published. They are kept
so the v2 docs in `docs/` can be compared with what v1 does.

`protocol.md` is the v1 wire specification; `tests/test_protocol.py` checks it against v1.
